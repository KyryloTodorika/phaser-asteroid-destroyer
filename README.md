# Phaser Asteroid Destroyer

A browser-based space shooter built with Phaser, TypeScript, and Vite. Fight through nine enemy waves, choose super shots, and defeat the final boss.

## Requirements

- [Node.js](https://nodejs.org/) `20.19.0` or newer (`22.12.0+` is also supported)
- npm

## Start the project

1. Clone the repository and enter its directory:

   ```bash
   git clone <repository-url>
   cd phaser-asteroid-destroyer
   ```

2. Install the dependencies:

   ```bash
   npm ci
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL shown in the terminal, usually:

   ```text
   http://localhost:5173
   ```

The development server reloads the game automatically when source files change.

## Controls

| Action | Control |
| --- | --- |
| Move | `W`, `A`, `S`, `D` |
| Fire | Left mouse button |
| Use super shot | `E` |
| Select a super shot | `1`, `2`, `3`, or click a card |
